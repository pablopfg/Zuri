# Issue tracker

Configuração usada pelas skills `mattpocock-skills:*` (substitui rodar `/setup-matt-pocock-skills`).

- **Especificação do trabalho:** `docs/especificacao.md`. Cada etapa é um bloco `**Etapa NN · …**`; os critérios de aceite estão no bloco e na tabela "Critérios de aceite adicionais".
- **Estado das etapas:** `.claude/memoria/progresso.md`.
- **Bugs e pedidos fora das etapas:** issues do GitHub deste repositório (`gh issue` ou as ferramentas do GitHub), escritas em pt-BR.
- **PR como fonte de pedidos:** desligado.
- Para o eixo "Spec" do `code-review`, a fonte é o bloco da etapa do nome da branch (`feat/etapa-NN-…`) em `docs/especificacao.md`.
